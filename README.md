
# PhotoRent — система аренды фото- и видеотехники

**Автор:** Широкова Арина  
**Учебная практика:** УП.01.01

## О проекте

PhotoRent — настольное WPF-приложение для просмотра и управления арендой фото- и видеотехники.

## Используемые технологии

- C#, WPF, .NET Framework 
- Microsoft SQL Server
- LINQ
- XAML

## Функциональные возможности

**Пользователь:**
- Регистрация и авторизация
- Просмотр каталога техники
- Поиск, фильтрация и сортировка
- Смена пароля

**Администратор:**
- Просмотр и редактирование техники
- Добавление и удаление записей
- Управление заявками на аренду
- Просмотр диаграммы
- Экспорт отчётов в DOCX, PDF и XLSX

## Безопасность

- Разграничение ролей User и Admin
- Хэширование паролей с помощью PBKDF2
- Капча после трёх неверных попыток входа
- Проверка вводимых данных

## База данных

База данных `DB_Shirokova_PhotoRental` содержит три основные таблицы:

- `Users` — пользователи
- `Equipment` — фото- и видеотехника
- `Rentals` — заявки на аренду

SQL-скрипт создания и заполнения базы: `UP_skript.sql`.

## Интерфейс

Приложение поддерживает светлую и тёмную темы оформления с сохранением выбора пользователя.
